# Experiment Design: Partition Size vs. Pruning Effectiveness

## Question and x axis

**Question:** How does `maxRowsPerPartition` affect how much of a table the planner can skip reading, for a fixed selective query?

**x axis:** `maxRowsPerPartition`, swept across 2, 8, 32, 128, 512, 1024 (log scale, since the values span multiple orders of magnitude).

## Metric and y axis

**y axis:** fraction of partitions read, computed from the planner's own decision=READ|PRUNED log lines as partitionsRead divided by partitionsTotal, for a single fixed query executed once per partition size. One curve is plotted: fraction of partitions read (y) against maxRowsPerPartition (x).

## Procedure

- Data: a synthetic trips table of 100,000 rows, generated by a committed script, with distance values uniformly distributed across a known range.
- Query: SELECT * FROM trips WHERE distance > T, where T is chosen so roughly 10% of rows qualify (fixed across all runs, so only maxRowsPerPartition varies between runs).
- Sort order: the input CSV is pre-sorted by distance before COPY, so partition min/max ranges are non-overlapping and pruning is meaningful to measure.
- Repetitions: 5 runs per partition size; report the median fraction of partitions read. The first (cold) run of the whole experiment is excluded from all partition sizes to avoid JVM and filesystem warm-up skew.
- Environment: run via the engine launcher script, same machine, same JVM (Java 25, default heap), logged via logs/engine.log and parsed with the engine's own SELECT queries against the logs table.

## Hypothesis

Smaller partitions let the planner prune more precisely, so the fraction of partitions read should decrease as maxRowsPerPartition decreases. Concretely: going from maxRowsPerPartition=1024 to maxRowsPerPartition=2 should cut the fraction of partitions read by at least half, since a 10 percent-selective predicate forces reading whole partitions it only partially matches at large partition sizes, while tiny partitions let pruning approach the true 10 percent selectivity.
